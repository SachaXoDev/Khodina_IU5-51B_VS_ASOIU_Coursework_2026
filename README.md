## 📌 О проекте и структуре варианта № 16

В рамках курсового проекта разработана 16-разрядная специализированная Система на Кристалле (**KOCTA-16 SoC**) на языке **Verilog**, собственный двухпроходный кросс-ассемблер на **Python** и полный программный стек для трех последовательных уровней сложности:

| Уровень | Оценка | Задание варианта № 16 | Реализация |
|---|:---:|---|---|
| **Уровень 1** | **«3»** | **Алгоритм № 16:** Бинарный поиск (Binary Search) | Поиск числа $X=77$ в массиве из 16 элементов в RAM за 102 такта без MMIO |
| **Уровень 2** | **«4»** | **Утилита № 23:** Стиральная машина (Washing Machine FSM) | 5-этапный автомат с отображением фаз на светодиодах MMIO и таймером обратного отсчета |
| **Уровень 3** | **«5»** | **Игра № 18:** Сокобан (Sokoban) $10 \times 10$ с **PUSH_LOGIC** | Аппаратный ускоритель коллизий в АЛУ (1 такт на ход), внутренние стены лабиринта, управление WASD / стрелками в реальном времени |

## 🏗 Архитектура процессора KOCTA-16

* **Архитектурный тип:** 16-битная гарвардская RISC-архитектура с раздельными шинами команд и данных.
* **Регистровый файл:** 16 регистров общего назначения (РОН `R0`..`R15`) по 16 бит.
  * `R0` — аппаратно заземленный ноль (`Hardwired Zero`: чтение всегда `0x0000`, запись игнорируется);
  * `R1`..`R10` — регистры данных и операндов;
  * `R11` — базовый указатель MMIO (`0xFF00`);
  * `R12` — регистр смещения / координатных векторов;
  * `R13` — базовый указатель на сегмент карты в RAM (`0x0010`);
  * `R14` — регистр связи (Link Register `LR` для подпрограмм);
  * `R15` — константа 1 / флаги АЛУ.
* **Адресное пространство:**
  * Память команд (ROM): 256 слов по 16 бит;
  * Память данных (RAM): 256 слов по 16 бит (`0x0000` .. `0x00FF`);
  * Регистры ввода-вывода (MMIO): `0xFF00` .. `0xFFFF`.

### 🚀 Аппаратное ускорение (Hardware Acceleration): `PUSH_LOGIC`
Для игры «Сокобан» в АЛУ процессора интегрирован аппаратный модуль `push_logic.v` (кодировка `0xE678`):
* **Входы:** код целевой клетки перед грузчиком ($c_1$) и код клетки за ящиком ($c_2$).
* **Выход за 1 машинный такт:**
  * Биты `[1:0]` — статус хода (`0`: ход заблокирован стеной, `1`: свободный шаг, `2`: толкание ящика);
  * Биты `[15:8]` — обновленный ASCII-код для клетки за ящиком (ящик на полу `$` или ящик на цели `*`).

## 📂 Структура репозитория

```text
.
├── rtl/                        # Аппаратные модули на Verilog-2012
│   ├── soc_top.v               # Верхний уровень Системы на Кристалле

│   ├── memory_top.v            # Память команд (ROM) и данных (RAM)

├── toolchain/                  # Инструментальное ПО

├── firmware/                   # Скомпилированные прошивки и листинги
│   ├── binary_search.hex / .lst

│   ├── tb_sokoban.v            # Тестбенч игры Сокобан (12 ходов к победе)
│   └── play_sokoban.py         # Консольный интерактивный мост для игры в терминале
├── docs/                       # Документация и отчетность
│   ├── Ходина_ИУ5_51Б_Курсовая_работа_Вариант16.docx # Официальный отчет РПЗ по ГОСТ (9 пунктов)
```

## ⚡ Быстрый запуск

### Требования:
* `python3` (версия 3.8+)
* `iverilog` и `vvp` (пакет Icarus Verilog)

### 1. Компиляция всех прошивок:
```bash
make assemble
```

### 2. Запуск сквозной симуляции в Icarus Verilog:
```bash
make sim_all
```
*Все тестбенчи проверяют корректность выполнения и формируют VCD-файлы для просмотра временных диаграмм в GTKWave.*

### 3. Интерактивная игра в терминале (Оценка «5»):
```bash
make play_sokoban
# либо: python3 sim/play_sokoban.py
```
* **Управление:**
  * Стрелочки на клавиатуре: $\leftarrow$, $\rightarrow$, $\uparrow$, $\downarrow$;
  * Английские клавиши: **WASD**;
  * Русская раскладка: **ЦФЫВ**;
  * Сброс уровня: **R** / **К**, выход: **Q** / **Й**.

## 📊 Результаты синтеза в ПЛИС (Xilinx Artix-7 XC7A35T)

* **Логические ячейки (Slice LUTs):** 435 шт. (~2.09% емкости кристалла).
* **Триггеры (Slice Registers / FF):** 348 шт. (~0.84%).
* **Блочная память (Block RAM 18K/36K):** 2 блока (ROM и RAM).
* **Максимальная тактовая частота ($F_{\max}$):** $\approx 110.0$ МГц.
* **Надежность:** Latch-free дизайн (полное отсутствие паразитных асинхронных защелок).
